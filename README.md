# Fuzzy Predicates in Relational Databases

This repository contains the database implementations and experimental
materials accompanying the paper on the representation and evaluation of
multidimensional fuzzy predicates in conventional relational database
management systems.

The proposed approach constructs multidimensional fuzzy predicates from
parameterized one-dimensional components and investigates alternative
implementation strategies, including materialized and dynamically computed
membership degrees.

## Repository contents

- `sql/` – SQL implementations of the database designs considered in the paper.

- The `D*.sql` files create the individual database designs.
- `example_data.sql` populates a created database with the geographic-coordinate
example used in the paper.

The repository is currently being prepared and additional reproducibility
materials will be added.
